# Wedding Invite

1. Edit `config.js` (names, date, venue, RSVP number, etc.).
2. Optional: add `assets/couple.jpg` and `assets/music.mp3`, then set `photo` / `music` in config.js.
3. Edit the link-preview text in the <head> of `index.html` (og:title / og:description).
4. Deploy: push this folder to GitHub and import it in Vercel (Framework Preset: Other, no build command),
   or run `npx vercel` inside this folder.
